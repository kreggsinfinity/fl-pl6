# ⚠️ Common English Mistakes Fixer (Repository 6 / Variety 6)

Automated video generator for **"90% of Learners Make This Mistake! Stop Saying THIS, Say THAT!"** 9:16 vertical reels.

## 🌟 Key Features
- **High Alert Visual Style**: Caution hazard badges and split red/green transformation cards.
- **The Golden Rule**: Breaks down the precise grammatical or conceptual why behind the error.
- **Pronunciation & Repeat**: Guided spoken audio repetition for muscle memory.
- **Psychological Hook**: Targets the universal human desire to avoid making embarrassing language errors.

## 🚀 How to Run
```bash
# 1. Generate mistake fixer reel
python run_generator.py

# 2. Publish to Facebook Page
python publish_facebook.py output/run_XXXX/common_mistakes_reel.mp4 output/run_XXXX/metadata.json
```

## 📱 Recommended Facebook Page Target
- **Page Concept**: *Speak English Correctly / Common Mistakes Fixer*
- **Target Audience**: Students preparing for IELTS/TOEFL and non-native speakers seeking error-free spoken English.
